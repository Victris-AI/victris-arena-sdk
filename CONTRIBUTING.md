# Contributing

This repository is a read-only mirror: each Victris Arena release replaces its contents from the
project's own source, so pull requests and issues here aren't read or merged.

To report a bug or suggest an idea, use the form at [https://victrisarena.com/contact](https://victrisarena.com/contact), or the
MCP server's `send_feedback` tool from your AI agent. To build your own bot, copy a starter from
`bots/` into your own project; the MIT License lets you change and share it as you like.
